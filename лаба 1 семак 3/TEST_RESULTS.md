# Проверка проекта

Проверено 2 ноября 2026 года на macOS arm64.

| Проверка | Результат |
|---|---|
| Сборка C++17 с Wall/Wextra/Wpedantic | Успешно, без предупреждений |
| Интерфейс C++: `python3 tests/test_cli.py ./dbms` | 844 проверки пройдены |
| C++: `tests/test_tree.cpp` | Вставки, поиск, пустое дерево, Complete-форма и две формы с пропусками — пройдены |
| Сборка Go, go1.26.2 | Успешно |
| `go test ./...` | Пройдено |
| `go vet ./...` | Замечаний нет |
| Интерфейс Go: `python3 tests/test_cli.py ./dbms-go` | 844 проверки пройдены |
| Контрольный запуск с записью фактического вывода | `examples/control_output.txt` |

Проверки интерфейса запускают отдельный процесс для каждого запроса и тем самым проверяют восстановление состояния из файла. Включены все основные команды, 120 случайных операций для каждого вида списка со сравнением с моделью, чтение в обе стороны, повторы, рост массива, дерево из 150 узлов, неверные индексы и аргументы, конфликт имён, пустой стек/очередь и повреждённые файлы. После каждого ошибочного запроса проверяется, что файл не изменился.

Это набор функциональных проверок; измерение производительности на больших объёмах и одновременный доступ нескольких процессов не проводились.

В исходный архив включены код и данные; исполняемые файлы собираются на компьютере пользователя командами из README.

Дополнительная проверка C++ с AddressSanitizer/UndefinedBehaviorSanitizer: сборка выполнена, но запуск остановлен после зависания на первом запросе в данной среде. Результат этой проверки не подтверждён и не включён в число пройденных проверок.
