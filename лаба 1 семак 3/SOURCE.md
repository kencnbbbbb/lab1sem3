# Источник примера

Использован репозиторий пользователя 1g1b1plt1w1:
https://github.com/1g1b1plt1w1/term3_prog_laba1

Изученный commit: a1b34af9f472da12cce275067663242399d62728.

Из примера заимствованы организация проекта, названия структур и операций, процедурные реализации линейных структур C++ и пакет линейных структур Go. Авторство этих исходных решений сохраняется за автором примера. В изученном снимке отдельного файла лицензии нет.

Для варианта 3 разработаны Complete Binary Tree, новая обработка запросов и файлов, проверки аргументов, автоматические тесты и пояснения. Исправлены возвращаемые значения операций стека/очереди C++, обратное чтение односвязного списка, вставка в пустые списки, работа с повторяющимися ключами, инициализация контейнеров, сохранение порядка стека и другие ошибки. Go использует пакет str вместо дублирования определений в main.go.

Методическое основание: предоставленная пользователем «Лабораторная работа №1. Абстрактные структуры данных», LR1_2026.pdf. Учебные материалы по АВЛ и красно-чёрным деревьям использованы для сопоставления видов деревьев; в варианте 3 эти виды не реализуются.
